Terms of Service Plugin Changelog

1.0.0 -- (to be determined)

  • Initial release. Extracted from an example previously developed as part of the Openfire core (org.jivesoftware.openfire.sasl.task.AcceptTermsTaskProvider), updated to match the "SASL2 Terms of Service Task" specification, and substantially extended:
    • Acceptance and document text moved from a single user property into two proper database tables (ofTosAcceptance, ofTosDocument), with install scripts for ten database platforms (see readme.html for which are and aren't natively detected by Openfire today).
    • A versioned repository of terms-of-service texts, with a draft/current/retired lifecycle, manageable from a new admin console page.
    • A public, unauthenticated HTTP endpoint serving the current terms as HTML, Markdown, or plain text, negotiated via the Accept header, with an admin-configurable announced URL for reverse-proxied deployments.
    • A new per-user admin console page showing acceptance history and allowing an administrator to record an acceptance on a user's behalf.
    • The plugin itself, and its package, class, database, and URL-path naming, generalized away from "SASL2" to plain "terms of service" (org.igniterealtime.openfire.plugin.termsofservice): the SASL2 task is this plugin's first enforcement mechanism, not an assumed-permanent one. The acceptance-recording mechanism was generalized into a standalone service (TosAcceptanceService) so that a future mechanism beyond the SASL2 task and the admin console can be added without changing either.
    • Admin console labels and page text moved into a translatable resource bundle (termsofservice_i18n.properties).
